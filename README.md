# arduino-assignment

This is our group project for the Arduino assignment. There are four of us, and each person wrote one part of the program on their own Git branch. We then merged everything into main. We used PlatformIO in VS Code to build it.

# Who did what

- Member 1 (Karolis, growkar7):** the Blink function. The LED blinks 3 times, pauses for a moment, then repeats.
- Member 2 (Abdulah):** the menu. Type 1 to calculate a sum or 2 to multiply.
- Member 3 (Leo):** asks for 2 numbers and calculates their sum.
- Member 4 (Korne):** asks for 2 numbers and multiplies them. 

# How to run it

1. Install VS Code and the PlatformIO extension.
2. Clone the project: <git clone https://github.com/growkar7/arduino-assignment.git>
3. Open the folder in VS Code and let PlatformIO set itself up.
4. Plug in the Arduino and click Upload.
5. Open the Serial Monitor at 9600 baud. The LED blinks, and you can use the menu there.
